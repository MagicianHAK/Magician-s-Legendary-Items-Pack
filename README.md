# Magician's Legendary Items Datapack

## Description
This datapack adds 6 legendary items. These are intended for pvp/smps and may not be balanced for pve.
The datapack is balanced around this gear:
- Full max diamond gear
- Level 1 strength potions
- Level 1 speed potions
- No Ender Pearls

## Give Commands

### Individual Items
- Ancient Helm: `/function legendaries:ancient_helm/give`
- Bloodthorn: `/function legendaries:bloodthorn/give`
- Earthen Belt: `/function legendaries:earthen_belt/give`
- Ender Cloak: `/function legendaries:ender_cloak/give`
- Enigma: `/function legendaries:enigma/give`
- Frenzy: `/function legendaries:frenzy/give`
- Recluse Shield: `/function legendaries:recluse_shield/give`
- Storm's Edge: `/function legendaries:storms_edge/give`
- Tempest Boots: `/function legendaries:tempest_boots/give`
- Terraprisma: `/function legendaries:terraprisma/give`
- Tidal Blade: `/function legendaries:tidal_blade/give`

### All Items
- All of them: `/function legendaries:give_all`

## Versions
This data pack is currently only for Minecraft 1.21.11

## Installation
This data pack is made with Beet. It is recommended that install the data pack and resource pack from modrinth for regular use.
- Data pack: https://modrinth.com/datapack/magicians-legendary-items
- Resource pack: https://modrinth.com/resourcepack/magicians-legendary-items-rp

## Dependencies
This data pack requires the resource pack to function correctly.
Both the data pack and resource pack must be installed.
