# Magician's Legendary Items Datapack

## Description
This datapack adds 6 legendary items. These are intended for pvp/smps and may not be balanced for pve.
The datapack is balanced around this gear:
- Full max diamond gear
- Level 1 strength potions
- Level 1 speed potions
- No Ender Pearls

## Give Commands

### Individual Items
- Tidal Blade: `/function legendaries:tidal_blade/give`
- Frenzy: `/function legendaries:frenzy/give`
- Ancient Helm: `/function legendaries:ancient_helm/give`
- Ender Cloak: `/function legendaries:ender_cloak/give`
- Earthen Belt: `/function legendaries:earthen_belt/give`
- Speed Boots: `/function legendaries:speed_boots/give`

### All Items
- All of them: `/function legendaries:give_all`

## Versions
This datapack is made for Minecraft 1.21.11

## Installation
1. Download both the datapack and resource pack.

2. Install the datapack:
Place the datapack ZIP into your world's `datapacks` folder.

3. Install the resource pack:
Place the resource pack ZIP into your Minecraft `resourcepacks` folder and enable it in-game.

4. Run `/reload` in-game.

## Dependencies
This datapack requires the included resource pack to function correctly.
Both the datapack and resource pack must be installed.
